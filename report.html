Analysis 3 · 외부 데이터 활용의 적절성

무리한 결합 대신 내부 구조 규명

검토 후보 — 국가별 기준금리·소비자물가(CPI)·실업률 등 거시지표, Churn_Modelling 원본.

판단 · 본 데이터는 합성(synthetic)으로 실제 고객·기간 식별키가 없어 거시지표를 시점/지역으로 정합 결합할 근거가 약하고, 원본 병합은 평가셋 누수 위험이 있습니다.

결론 · 외부 결합을 강행하기보다 ‘잔고 역설 = 국가(독일) 교란’처럼 데이터 내부 구조를 규명하는 데 집중했습니다. 실데이터 적용 시 국가별 금리·경기지표를 시점 결합하면 설명력 향상 여지가 큽니다.
